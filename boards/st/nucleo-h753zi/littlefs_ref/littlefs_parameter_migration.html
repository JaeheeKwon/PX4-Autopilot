Nucleo-H753ZI LittleFS Parameter Storage Migration

Step-by-step migration from the active raw flashfs parameter backend to file-backed PX4 parameters stored in a LittleFS volume under /fs/flash/params.

Goal Current And Target State Flash Layout Migration Steps Validation Failure Modes Final Checklist

Goal

The param module should use a normal file on a mounted LittleFS filesystem. The module does not discover LittleFS by itself; it only uses the filesystem when the flash backend is disabled and param select receives a mounted file path. 

board_app_initialize()
  -> creates an MTD partition from internal flash
  -> mounts LittleFS at /fs/flash
  -> rcS sources generated rc.filepaths
  -> rcS runs: param select /fs/flash/params
  -> param load-or-init loads or creates /fs/flash/params
  -> later param save writes BSON parameters to LittleFS
Remove FLASH_BASED_PARAMS before relying on param select. With that define enabled, PX4 keeps using the flash backend for default parameter persistence.

Flash Layout

Region Sectors Address Range Size
Bootloader 0 0x08000000 - 0x0801ffff 128 KiB
PX4 app 1-11 0x08020000 - 0x0817ffff 1408 KiB
LittleFS params 12-15 0x08180000 - 0x081fffff 512 KiB

The linker script, bootloader flash limits, and firmware metadata must agree on this layout. If only one of them is changed, firmware upload or runtime writes can overwrite the LittleFS partition.

Migration Steps

  1. Use parameter-only storage

    Keep CONFIG_BOARD_ROOT_PATH separate from the LittleFS volume and set only CONFIG_BOARD_PARAM_FILE="/fs/flash/params".

    This keeps /fs/flash dedicated to parameters instead of making it general board root storage for config scripts, backups, hardfault logs, external airframes, and update directories.

  2. Reserve flash for LittleFS

    Update boards/st/nucleo-h753zi/nuttx-config/scripts/script.ld.

    FLASH      (rx) : ORIGIN = 0x08020000, LENGTH = 1408K /* LittleFS params in sectors 12-15 */

  3. Update bootloader flash limits

    Update boards/st/nucleo-h753zi/src/hw_config.h.

    #define BOARD_FLASH_SECTORS            (11)
#define APP_RESERVATION_SIZE           (4 * 128 * 1024)

  4. Update firmware image metadata

    Update boards/st/nucleo-h753zi/firmware.prototype.

    "image_maxsize": 1441792

    This is 1408 KiB and must match the linker app flash window.

  5. Remove the flashfs parameter backend

    Remove this define from boards/st/nucleo-h753zi/src/board_config.h:

    #define FLASH_BASED_PARAMS

    With the define removed, param select can select the file-backed parameter store.

  6. Mount LittleFS during board initialization

    Replace the parameter_flashfs_init() block in boards/st/nucleo-h753zi/src/init.c with the LittleFS mount helper from littlefs_ref/src/init.c. 

    #define PARAM_LITTLEFS_DEVICE       "/dev/mtd_params"
#define PARAM_LITTLEFS_MOUNTPOINT   "/fs/flash"
#define PARAM_LITTLEFS_ERASE_BLOCKS 4
#define PARAM_LITTLEFS_TEST_FILE    PARAM_LITTLEFS_MOUNTPOINT "/.mount_test"

    The helper must initialize progmem, partition the final four erase blocks, register /dev/mtd_params, create mount directories, mount LittleFS with autoformat, and verify writability.

  7. Point generated rc.filepaths at LittleFS

    Add this to boards/st/nucleo-h753zi/default.px4board:

    CONFIG_BOARD_PARAM_FILE="/fs/flash/params"

    After rebuild, confirm:

    set PARAM_FILE /fs/flash/params
set BOARD_ROOT_PATH /fs/microsd

  8. Add rc.board_early as a storage guard

    Copy littlefs_ref/init/rc.board_early to the active board init directory. It disables generic storage features so logs, backups, external airframes, and update directories do not fill the parameter partition.

  9. Merge LittleFS NuttX tuning

    Update boards/st/nucleo-h753zi/nuttx-config/nsh/defconfig.

    CONFIG_FS_LITTLEFS=y
CONFIG_FS_LITTLEFS_PROGRAM_SIZE_FACTOR=1
CONFIG_FS_LITTLEFS_READ_SIZE_FACTOR=1
CONFIG_FS_LITTLEFS_CACHE_SIZE_FACTOR=1
CONFIG_FS_LITTLEFS_BLOCK_CYCLE=-1

  10. Rebuild

    make st_nucleo-h753zi_default

    Check generated paths and image size:

    cat build/st_nucleo-h753zi_default/etc/init.d/rc.filepaths
ls -l build/st_nucleo-h753zi_default/st_nucleo-h753zi_default.bin

  11. Flash and boot

    The first boot formats sectors 12-15 as LittleFS. Existing flashfs parameter data in sector 15 is erased. 

    dmesg
ls /fs
ls /fs/flash
param status

  12. Validate parameter persistence

    param set COM_DISARM_PRFLT -1
param save
ls /fs/flash
reboot
param show COM_DISARM_PRFLT
param status

Validation Expectations

  • /fs/flash/params exists after first parameter initialization.
  • param status reports the selected default file path.
  • A saved parameter value survives reboot.
  • parameters_backup.bson is absent unless backups were deliberately enabled.
  • The app image fits inside the 1408 KiB firmware limit.
Do not use /fs/flash for logs, missions, or large files unless more flash sectors are reserved and the app image limit is revisited.

Final Checklist

  • FLASH_BASED_PARAMS removed from active src/board_config.h.
  • parameter_flashfs_init() removed from active src/init.c.
  • LittleFS MTD partition and mount helper added to active src/init.c.
  • LittleFS mountpoint is /fs/flash.
  • CONFIG_BOARD_PARAM_FILE="/fs/flash/params" is set.
  • Generated rc.filepaths selects /fs/flash/params.
  • Linker app flash length is 1408 KiB.
  • Bootloader app flash sectors end at sector 11.
  • Firmware image_maxsize is 1441792.
  • NuttX LittleFS tuning options are merged.
  • First boot formats LittleFS successfully.
  • param save creates /fs/flash/params.
  • Saved parameter values survive reboot.
