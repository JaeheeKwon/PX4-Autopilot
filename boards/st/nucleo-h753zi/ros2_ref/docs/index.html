Reference Implementation

Component Description Path Role
PX4 startup hook Board-side startup extension that launches the DDS client after PX4 boots on NuttX. ../config/rc.board_extras Starts uxrce_dds_client on /dev/ttyS1.
ROS 2 package Host-side reference package containing the health monitor executable and launch file. ../ros2_ws/src/nucleo_px4_ros2_ref Contains the reference bridge health monitor node.
Agent helper Shell wrapper for starting the Micro XRCE-DDS Agent with the board's serial settings. ../scripts/run_agent_serial.sh Runs MicroXRCEAgent serial --dev /dev/ttyUSB0 -b 921600.
Workspace helper Host setup script that prepares the ROS 2 workspace and message dependencies. ../scripts/build_ros2_workspace.sh Creates and builds a host ROS 2 workspace with px4_msgs.
