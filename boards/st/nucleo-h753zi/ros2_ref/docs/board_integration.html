Nucleo-H753ZI Board Integration

Firmware-side configuration for running the PX4 uXRCE-DDS client on USART6 while preserving the existing USB MAVLink HITL link.

Physical Wiring

Firmware Configuration

This checkout already enables the client in boards/st/nucleo-h753zi/default.px4board: 

CONFIG_MODULES_UXRCE_DDS_CLIENT=y

Build and flash:

make st_nucleo-h753zi_default
make st_nucleo-h753zi_default upload

Startup Options

Manual start

nsh> uxrce_dds_client start -t serial -d /dev/ttyS1 -b 921600
nsh> uxrce_dds_client status

Boot-time start

cp boards/st/nucleo-h753zi/ros2_ref/config/rc.board_extras \
   boards/st/nucleo-h753zi/init/rc.board_extras

Rebuild and flash after copying the file. PX4 sources rc.board_extras late in startup, after core board defaults, airframe setup, and the main modules are started.

Namespaces

By default the topics are un-namespaced. For multi-vehicle testing, start the PX4 client with -n uav_0 or set UXRCE_DDS_NS_IDX. The reference ROS 2 node accepts a px4_namespace parameter.
