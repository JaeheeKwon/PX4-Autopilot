Commander Arming Denied Debug Plan

A runbook for diagnosing PX4 commander preflight and arming denials on the ST Nucleo-H753ZI HITL target.

Markdown source: commander_arming_denied_debug_plan.md.

Goal

When arming is denied, identify whether the root cause is a direct commander gate, the selected mode, a health component, a HITL data path failure, or a saved-parameter mismatch. Do not start with force arming; collect the denial evidence first.

Mode Check

Commander evaluates readiness against the current vehicle_status.nav_state. On Nucleo-H753ZI HITL, COM_RC_IN_MODE=4 ignores manual input, so manual-control modes commonly fail. Use Hold/auto:loiter first.
